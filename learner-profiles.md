---
title: Rclone Learner Profiles
---

- A professor wants to synchronize work on a local drive with an external backup.  
- A researcher needs to move a folder of large datasets from one cloud storage location to another, such as from Google Drive to Box. Rclone can perform the batch transfer and run in the background.  
- A student wants to create a simple backup command to copy their current work to an external drive.  
- A researcher wants to regularly back up a project directory to cloud storage without manually copying each file.  
- A research team needs to transfer thousands of files between a local server and an institutional cloud-storage account.
